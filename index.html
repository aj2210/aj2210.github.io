Open source

eloquent-agent

A read-only Claude agent for Laravel applications. It answers plain-English questions about your data — "how much did we refund last month, by reason?" — by calling tools rather than by writing SQL.

That distinction is the whole design. The model emits a structured description of what it wants, and a compiler checks every column and operator against a config allowlist before anything reaches the database. Denied columns cannot be selected, filtered on, sorted by or grouped by, because filtering and grouping leak values that a SELECT alone would not.
